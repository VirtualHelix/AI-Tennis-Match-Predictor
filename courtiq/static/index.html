A few things the model cannot know.

Useful context for every estimate.

Data freshness and tournament context

The app uses the server’s default forecast date and the loaded historical snapshot. Tournament round is unspecified. The source often provides tournament start dates instead of exact match times, so the model uses a conservative availability delay; it cannot measure precise rest days or infer a player’s mental state.

Optional shot-level observations

Charted forehand-side, backhand-side, serve, and return statistics can add detail when enabled and supported by actual observations. Coverage is uneven. Historical publication time must be known, or research use must explicitly acknowledge the availability limitation. Missing observations are not fabricated.

Reading the probability

Probabilities describe uncertainty. A 60% illustration represents a 0.60 estimated chance of a win, not a certain result. Evaluation scores and calibration describe historical predictions; they do not guarantee performance for a particular player, surface, or future season.
